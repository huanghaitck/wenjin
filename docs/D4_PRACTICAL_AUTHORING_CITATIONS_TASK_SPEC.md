# D4 Task Spec｜Practical Authoring and Citations

状态：实施中
日期：2026-08-10

## 目标

根据 D3 真实界面反馈，把文章工作台从架构 Demo 推进到可连续试写、插注和导出的版本。本轮只处理
写作体验、两个预设期刊模板、结构化注释和模型评测。

## 范围

1. 预置《历史研究》和《中国社会科学》两个带版本、来源网址、规范日期和核验状态的模板；
2. 选择正文后建立注释锚点，支持核页插注、元数据已核页码待补、用户现成注释格式化三种状态；
3. 注释提案须人工批准，修改注释产生新版本，旧版不覆盖；
4. 注释可以关联 Evidence、SourceVersion、Page、Block，并同时保存 original_page 与 digital_page；
5. Markdown 导出标准脚注，DOCX 导出真实 OOXML 脚注并生成 fidelity report；
6. 重组文章工作台的稿件导航、画布状态、选区动作、注释侧栏和版本信息；
7. 用本地 `histra-qwen3.5:9b-64k-fast` 与当前 Codex 参考稿做相同材料的保真润色对照。

## 模型评测门禁

- 引文、数字、脚注和来源标识完整；
- 不新增事实；
- 不把“可能、可以说明、提示”提升为“证明、表明、导致”；
- 冷启动与热启动耗时分开记录；
- 输出只保存为候选，不自动采用。

## 不做

- 不复制完整 Microsoft Word 功能；
- 不自动猜测页码、档号、作者或出版信息；
- 不把 Evidence 自动转成正式脚注；
- 不迁移 Library Processing，不打包桌面客户端；
- 不声称两个期刊模板在未来持续有效。

## 验收

- 两个预设模板在设置与文章工作台中显示来源和版本；
- 选择一段文字后可创建、批准、修订并回到来源页查看注释；
- 锚点文字变化时注释进入待复核；
- Markdown 与 DOCX 均导出脚注，DOCX 通过结构审计和页面渲染；
- 模型对照报告记录冷/热延迟、标记保留和解释强度变化；
- 全部既有测试和新增 D4 测试通过。
