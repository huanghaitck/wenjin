# ADR 0015：已登录学术数据库连接器与检索收件箱

## 问题

知网、读秀、学校发现系统等强文献库通常要求机构或个人登录，并会对自动化访问、批量下载、验证码和授权范围作出限制。若把检索策略、网站操作和证据资格混成一个“爬虫”，既难维护，也会让题录命中被误当成可引用材料。

## 决定

1. 采用“连接器/MCP + Skills + 人工门禁”三层结构。
2. 连接器/MCP 只负责稳定、可审计的网站动作：在用户可见且已经授权的浏览器会话中检索、翻页、读取题录、打开详情页，以及下载用户有权取得的 PDF 或 CAJ。
3. 登录凭据、Cookie 和机构授权不进入项目数据库；程序不得绕过验证码、付费、并发限制或访问控制。遇到验证码、授权提示、批量下载警告和文件确认时，必须暂停并交还用户。
4. Skills 负责编制检索式、同义词和异名组合，安排数据库顺序、停止条件、去重规则和材料层级，不直接保存账号状态。
5. 所有命中先进入“检索收件箱”，资格保持 `DISCOVERED`，再由研究者分为：拟纳入项目、待读全文、仅题录、重复版本、无权访问、排除。
6. 每次分流保存决定人、依据和时间；重新分流追加新决定，不覆盖历史。
7. 只有下载或导入、完成版本验收并核对原页后，材料才可进入阅读、证据和引用流程。

## 批量检索

批量工作以“检索任务包”为单位，保存研究问题、数据库、检索式变体、时间范围、执行时间、结果数和停止原因。程序可以串行或低并发执行用户可见的普通检索动作，但不能用批量名义扩大下载权限。

## 界面

联网研究页首先显示检索任务和命中列表。每条结果始终显示来源数据库、题名、作者、年代、访问状态和当前人工分流；默认不自动加入项目。研究者可以按六种去向筛选，集中处理“待读全文”和“无权访问”，并从“拟纳入项目”进入文件验收。

## 后果

新增数据库时只需实现网站动作连接器，研究方法与分流规则可复用。公开 API 仍直接工作；强文献库依赖研究者自己的合法会话，不能保证无人值守完成。
