# ADR 0007｜Versioned Section Writing before Broad Automation

状态：Accepted
日期：2026-08-10

## 决定

D1 之后先实现版本化分节写作，而不是立即扩大数据库数量或自动生成长文。文章由 Manuscript、
Section 和 immutable Section Version 组成；模型只能创建 Writing Proposal，人工批准后才更新当前
章节版本。

润色使用“受保护标记”门禁：原文中的直接引语、数字、脚注标记和显式来源引用必须继续出现。
分节写作必须绑定已批准 Evidence Freeze。批量阅读和学术史功能首先产生带页块引用的中间对象，
不直接成为正文证据。

研究网页与数据库遵循合法访问边界。系统可以有界抓取公开资源，或在用户已获授权的会话中辅助
操作；不得绕过许可证、访问控制、验证码、付费墙或技术限制。

## 理由

教授最早能反复使用的价值是修改已有文章和逐节推进，而不是一次生成完整论文。版本化提案和
冻结证据能把语言改写与事实判断分开，也让后续长文、期刊模板和评审共享同一可审计基础。
