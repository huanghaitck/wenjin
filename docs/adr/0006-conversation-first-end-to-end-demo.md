# ADR 0006｜Conversation-first Demo and Research Browser Boundary

状态：Accepted
日期：2026-08-10

## 决定

启动 D1 跨里程碑纵向 Demo。应用以对话为首页，以项目为工作边界，以图书馆为跨项目材料目录；所有研究对象可在对话和右侧上下文面板中被引用。

项目加入图书馆材料时，选定一个精确 File Version，将原文件复制到项目来源目录并沿用既有页面处理链。图书馆身份与项目来源身份通过显式桥接记录关联，不能用哈希替代作品身份。

研究浏览器采用渐进实现：D1 保存用户授权域名、起始 URL 和操作回执，并以系统浏览器打开；公开数据库由受限 connector 调用。桌面阶段再引入受控 WebView/Chromium 与 Computer Use。任何登录凭证、Cookie 或访问令牌均不得进入项目数据库。

证据、主张、冻结包与写作版本使用项目 SQLite 持久化。只有人工提交的、指向 `research_usable` 页面块的 Evidence Item 可以进入冻结包；只有人工批准的冻结包可以驱动试写。冻结保存精确来源版本快照，但来源新版本不会抹除旧记录。

## 理由

对话是教授表达研究意图和作出决定的自然入口；右侧研究对象保持来源和状态可见，避免聊天内容与证据系统脱节。先打通一条完整闭环，能验证产品假设，又不需要提前建设桌面浏览器内核、向量数据库或复杂多代理平台。

## 后果

- D1 会在一个本地进程内跨越原路线图 M6-M11 的少量能力，但不宣称这些生产阶段全部完成；
- 后续里程碑继续强化 connector、浏览器控制、学术对话、翻译、引用样式、长期记忆与桌面包装；
- 任何成功外观必须对应真实持久化状态，未配置能力明确显示为不可用。
