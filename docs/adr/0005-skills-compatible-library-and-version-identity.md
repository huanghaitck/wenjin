# ADR 0005｜Skills-Compatible Library and Version Identity

状态：Accepted  
日期：2026-08-10

## 决定

在开放网络检索之前加入 M5 研究图书馆。图书馆与项目数据库分离，材料默认原地索引；目录扫描
必须由用户明确发起并先形成候选，入库必须再次人工批准。

持久身份分为 Work、Edition、File 和 File Version。SHA-256 只作为 File Version 的精确指纹与
重复判断依据。File 以持续的位置记录维持身份；同一路径内容变化时新增 File Version，Work 与
Edition 不变。跨路径书目相似只形成待用户确认的关系，不自动合并。

M5 兼容 `SKILL.md` 的指令与能力声明，记录实际说明文件哈希，但不执行任意脚本。首个内置 adapter
遵循 historical-material-intake 的只读验收、版本关系、资格分级和人工门禁原则。

## 理由

历史材料的版本、译本、重印、OCR 和路径关系不能被文件哈希压扁。若哈希兼任作品主键，任何
人工修正都会让文献看似成为另一部作品，也无法呈现版本沿革。独立图书馆还可让多个研究项目
复用同一材料而不复制或移动原件。

## 后果

- 可以精确展示“作品未变、文件版本已变”；
- 精确重复、书目相似和同一作品是三个不同判断；
- 图书馆记录不自动获得引用资格；
- 桌面打包前目录选择暂用文本路径输入，Tauri 阶段再替换为系统目录选择器；
- 后续联网取得文件也必须经过相同的版本与人工验收入口。
