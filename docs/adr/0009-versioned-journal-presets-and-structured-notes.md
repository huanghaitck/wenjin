# ADR 0009｜Versioned Journal Presets and Structured Notes

状态：Accepted
日期：2026-08-10

## 背景

D3 已证明结构化稿件修订、DOCX/Markdown 适配和上下文对话可以运行，但文章工作台仍缺少真正可用
的注释对象，期刊模板也只有宽泛占位信息。把脚注直接写进段落文本会破坏锚点、版本和来源核验；把
Evidence 回链当成投稿脚注则混淆研究证据与出版格式。

## 决定

1. 稿件注释由正文锚点、独立注释版本和来源核验状态组成，不把脚注正文塞进段落字符串；
2. Evidence 回链继续证明论断依据，Journal Note 负责读者可见的注释，二者可以关联但不等同；
3. 注释创建先进入待审状态，人工批准后才成为当前正式注释；
4. 核页注释必须保存精确来源版本、物理页和原书页，元数据已核但页码未定时显示醒目占位符；
5. Markdown 导出标准脚注，DOCX 导出 OOXML 真脚注，并生成保真报告；
6. 期刊模板是带来源、规范日期和核验状态的版本化配置，不是永远有效的字符串；
7. 内置两个模板：《历史研究》公开规范参考版、《中国社会科学》2026 版；投稿前均提示复核。

## 模板来源边界

- 《历史研究》：使用云南大学公开镜像《〈历史研究〉关于引文注释的规定》作为参考；公开页面未能
  证明其仍是 2026 年投稿最新版，模板状态为 `REFERENCE_NEEDS_PRE_SUBMISSION_RECHECK`。
- 《中国社会科学》：使用中国社会科学杂志社 2025-01-01 生效的投稿须知和 2026 年修订的期刊引文
  注释规定，状态为 `OFFICIAL_CURRENT_CHECKED_2026_08_10`。

## 后果

- 项目 schema 增量加入注释及模板修订表，旧 Journal Template、Section 和 Document Revision 保留；
- 段落被修改导致锚点文字不匹配时，注释转为待复核，不猜测新位置；
- DOCX 脚注的版式仍需 Word/LibreOffice 渲染复核；复杂原稿往返不因本功能自动变成无损。
