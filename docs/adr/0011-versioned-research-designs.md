# ADR 0011｜可导入、可讨论、可批准的研究计划版本

状态：Proposed；等待 Demo 验收后接受  
日期：2026-08-11

## 背景

研究对话目前只有消息、札记和项目状态。模型能够读取来源与证据，却不知道研究者已经批准的正式
问题、时间窗、比较单位和停止边界。真实测试中，这会让模型重新发明项目，或把页面处理状态误当
研究优先级。

另一方面，研究计划不能成为封死的系统提示。历史研究会在阅读、补证和讨论中改变；模型也应当能
提出新的比较维度。关键是区分当前有效的研究合同与尚未批准的建议，保存每次人工决定，而不是禁止
探索。

## 决定

### 1. 项目区分研究者基线与共同批准计划

研究计划是项目级对象，不属于某一篇稿件或某一条对话，但有两种角色：

- `researcher_baseline`：研究者已经掌握、用于比较和纠偏的心中方案；默认不提供给 Agent；
- `shared_design`：研究者与 Agent 讨论后共同接受的执行合同；批准后提供给 Agent。

每种角色任一时刻最多有一个 `approved` 版本。批准同角色的新版本时，旧批准版转为
`superseded`，但内容、来源和决定记录永久保留。

每个版本至少保存：

- 标题、正文和变更摘要；
- 计划角色：研究者基线或共同计划；
- 来源形式：导入、人工编辑、对话提升或模型建议；
- 基础版本；
- `draft / approved / rejected / superseded` 状态；
- 创建者、模型快照（如有）、创建时间；
- 决定人、决定理由和决定时间。

### 2. 计划允许四种进入方式

1. 粘贴或导入已有 Markdown / 纯文本计划；
2. 人工在计划面板中创建、编辑草案；
3. 把研究对话或已批准研究札记提升为草案；
4. Agent 调用工具提交修订建议。

上述入口都只创建草案。只有人工批准才能改变当前批准版。DOCX 导入可复用文档适配器，但不是最小
版本的前置条件。

### 3. 支持独立构思与按计划执行两种对话状态

在“独立构思”中，Agent 只获得研究任务、获准材料和必要边界，不获得研究者基线，也不获得当前
共同计划的具体答案。研究者把 Agent 的提案与自己的基线并列比较，判断一致、遗漏、冲突和意外
启发，再决定如何纠偏。系统不得把研究者基线泄漏进工具回执或隐藏系统提示。

在“按计划执行”中，每次模型调用自动获得当前共同批准计划。它负责推进阅读、检索、证据与写作
任务，但仍可提出计划修订。

两种状态由研究者显式选择并在运行回执中显示；独立构思不是清空项目，也不会删除历史计划。

### 4. Agent 可以发明，但必须标明资格

模型可以提出：

- 新材料线索；
- 新比较维度；
- 计划中的冲突、缺口或停止条件修订。

这些内容默认只存在于对话。需要进入计划时，模型调用 `research_design.propose`，生成待人工决定的
草案。模型不得把自己的建议描述成已批准计划，也不得直接覆盖当前版本。

### 5. 注入的是共同计划，不是研究者基线或聊天摘要

“按计划执行”时，运行时向主模型增加独立的 `APPROVED_SHARED_RESEARCH_DESIGN` 系统上下文，
包含稳定版本 ID 和计划正文。“独立构思”时只声明该运行未提供研究者基线与共同计划，防止模型把
缺失上下文伪装成已知计划。若项目尚无共同批准版，则明确写明“无共同批准版”，不得从旧聊天中猜
一个正式计划。工具回执、来源资格和证据状态继续独立提供，不能把计划文本当作史料证据。

### 6. 计划与执行状态分离

研究计划说明“研究什么、怎样比较、何时停止”；阅读任务、检索票、证据冻结和稿件说明“当前做到
哪里”。计划批准不自动启动检索、冻结证据或改写稿件。反过来，某次运行完成也不自动修改计划。

## 最小界面

研究对话右侧增加“研究计划”标签：

- 顶部显示当前批准版、版本号、批准人和时间；
- 分栏显示“研究者基线”和“共同计划”，前者明确标记默认不向 Agent 提供；
- 下方显示草案及其来源；
- 支持粘贴/导入、从札记提升、比较版本、批准和拒绝；
- 支持发起“独立构思”并把结果与研究者基线并排查看；
- 对话中模型提出的未批准建议保持清晰标记。

文章工作台只显示当前批准版摘要与版本号，避免形成第二套计划编辑入口。

## 简洁性约束

- 不建立通用工作流 DSL、计划图数据库或多 Agent 任务编排器；
- 不把聊天全文自动总结为计划；
- 不用文件哈希决定一份计划是否仍有效；
- 不自动合并两个草案；冲突由研究者选择或编辑；
- 不用模型替研究者裁定其提案是否符合隐藏基线；
- 最小版本只支持 Markdown / 纯文本导入，其他格式后加；
- 计划注入不替代按需读取来源、原页和证据工具。

## 后果

- 模型获得稳定方向，同时保留受控探索能力；
- 既有研究可以导入，不必从空白对话重建；
- 每次计划变化都有版本、来源和人工决定；
- 后续阅读任务、联网检索和写作可以记录所依据的计划版本。
