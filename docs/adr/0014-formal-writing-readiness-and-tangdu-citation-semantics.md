# ADR 0014：正式写作门禁与《唐都学刊》引注语义

## 问题

秦岭项目的批准研究设计要求三组核心材料各形成约 30—50 条有效事件，并完成学术史与外围材料定位。实际仅有 16、10、9 条获批事件，学术史条目为 0，冻结包只覆盖三种一手文本，但程序仍允许把分节试写导出并称为正式论文。

同时，《唐都学刊》把两类文字分开处理：来源引证使用正文上标的 `[序号]具体页码`，同一来源复引沿用序号，文后列参考文献；只有说明性、解释性文字才使用当页脚注。原模板虽然保存了规则文字，却没有把这种职责分离落实到 Word 渲染和研究门禁。

## 决定

1. 批准研究设计中明确写出的数量要求必须成为程序可见的正式写作门禁。
2. 未满足门禁时仍可保存札记、表格、章节试写和审稿样稿，但导出状态必须标为 `RESEARCH_NOT_READY`，不得称作可投稿成稿。
3. 《唐都学刊》成为内置、带版本的模板：事实与引文出处走正文顺序编码和文后参考文献；说明性文字走真实 Word 脚注。模板以用户提供的 2026 年最新刊发须知为当前版本，执行 GB/T 7714—2025；官网旧页作为已被替代的来源保留。
4. 项目图书馆“已有材料”不等于“已读、已冻结、已进入论证”。学术史、外围旅行者和背景材料必须有独立的阅读与登记状态。
5. 错误稿、旧冻结和旧评审保留为失败样本，不覆盖、不删除。
6. 一手史料、背景研究和学术史材料只要正文实际引用且原页、书目均经人工核验，就共享同一套文后顺序编码；图书馆入库本身不会添加参考文献。
7. 书架只承担组织与检索，可人工移动，但不改变来源资格、证据状态或原文件位置。
8. 作者与投稿信息按稿件单独保存，必填联系信息完整时才附加到导出稿末。

## 依据

- 用户提供的《唐都学刊》最新刊发投稿须知：采用 GB/T 7713.2—2022 与 GB/T 7714—2025。
- 《唐都学刊》2026 年第 2 期穆渭生论文刊例：包含约 300 字摘要、两级标题、多张表格、解释性脚注、16 条文后参考文献及文后英文信息。
- 《唐都学刊》官网《投稿须知》，2023-12-27 发布，仍写 GB/T 7714—2015，作为旧版对照保存。
- 秦岭项目人工批准的《共同计划 v1｜1871—1875连续跨越比较》。

## 后果

研究者会更早看到“材料尚未达到正式成稿条件”，但不会因此失去试写和导出供讨论的能力。模板负责排版和引注语义，不能替代材料阅读与学术史建设。
