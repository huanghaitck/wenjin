# 问津 0.1.1 发布验收表

本表按用户能够看到和完成的工作流验收，不以“代码中存在某个函数”代替可用性。

| 顶层入口或承诺 | 0.1.1 可完成的闭环 | 发布验收 |
|---|---|---|
| 项目工作区 | 默认入口；在问津默认目录或研究者选择的本地文件夹新建项目；登记已有项目；切换项目；显示阶段、研究对象、待决定事项、下一步与最近活动 | 单元测试、浏览器中英文截图、桌面文件夹选择器 |
| 项目续接与恢复 | 重新启动后恢复注册表中的项目；移动项目可登记新路径；外置项目进入启动备份；数据库与项目材料恢复为新项目副本 | 外置项目与完整项目包回归测试 |
| 研究对话 | 新建线程、选择模型与权限、读取有界项目上下文、保存运行与审批状态 | 单元测试与既有桌面冒烟 |
| 研究图书馆 | 只读盘点、分页恢复、建议分类、人工入库、作品/版本/文件分层、双层图谱回到来源 | 单元测试与真实界面截图 |
| 文章工作台 | 稿件与章节、版本化修改、选区返修、脚注与参考文献、DOCX 往返、评审与导出 | 单元测试与真实 DOCX 渲染检查 |
| 技能与插件 | 核心 Skills、领域包安装和校验、权限限定 MCP、用户本地数据绑定 | 单元测试与安装包冒烟 |
| AI 与 Agent | Ollama/OpenAI 兼容模型发现、主辅模型、MoA、研究人格、三档 Computer Use 权限、Codex/MCP/CLI | 连接测试、权限测试与安装包冒烟 |
| 中英文 | 六个顶层入口、项目工作区、模型与写作主要界面；中文研究内容本身不被机器翻译 | 浏览器中英文截图与字符串检查 |

## 明确不冒充已实现的功能

- 0.1.1 不在软件内删除或移动项目目录；移动后通过“打开已有问津项目”登记新位置。
- 没有自动更新和代码签名。
- macOS 尚未经过真实设备构建与测试。
- 复杂 DOCX 域、修订、批注和任意嵌入对象仍需在 Word 中复核。
- 受限数据库不做无人值守登录、验证码绕过或批量下载。
- 领域 Agent 工作区、模型岗位和清单内白名单MCP工具已启用；其他专用面板和图谱适配器声明只在核心存在对应入口时生效。
- 微信连接仍为仅入站私聊文字的实验功能。
