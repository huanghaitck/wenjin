# D2 Task Spec｜Evidence-preserving Reading and Section Writing

状态：已批准，实施中
日期：2026-08-10

## 目标

让 D1 的来源、证据和冻结包第一次进入日常文章修改。用户可以导入或粘贴 Markdown 稿件，按章节
管理版本，对单一章节请求保真润色或基于冻结证据的分节试写；模型输出永远先成为提案，经人工
对照后才成为新的章节版本。

## 第一优先闭环

1. 导入 Markdown 或粘贴现有文章，按标题切成稳定章节；
2. 选择章节、操作类型、写作要求和可选冻结包；
3. `polish` 保护引文、数字、脚注标记和来源引用，不能改变事实强度；
4. `section_draft` 必须绑定已批准 Evidence Freeze；
5. 显示原文与提案，人工批准或拒绝；
6. 批准产生新版本，原章节版本不覆盖；
7. 组合当前章节版本并按期刊模板导出 Markdown。

## 配套最小能力

- 批量阅读任务只接受用户选择的项目来源、页范围、问题和停止条件；
- 阅读札记保存实际使用的页块引用，不把摘要提升为证据；
- 学术史条目区分立场、贡献、限制、与当前问题的关系及来源引用；
- 期刊模板第一版保存章节顺序、标题规则和注释说明，不假装自动满足全部投稿细则；
- 公开网页可有界取得；授权数据库只操作用户已有访问权，不绕过许可、付费墙、验证码或访问控制。

## 写作门禁

- 润色不允许新增来源事实；模型提案缺少被保护的引文、数字或脚注标记时自动阻断；
- 分节试写只使用冻结包中的 Claim/Evidence；
- 用户可以直接编辑提案，但批准时保存最终文本、基础版本、操作、模型快照和证据引用；
- 大规模阅读按批次形成札记和覆盖率，不把整本书一次性塞入主模型上下文；
- 正式长稿仍由一个写作主体逐节推进，不并行拼接多份正文。

## 完成标准

- 稿件、章节、版本、写作提案、决定和导出重启后可恢复；
- 原稿不会被覆盖；
- 受保护标记缺失的润色提案无法批准；
- 未批准冻结包不能驱动分节试写；
- 批量阅读札记可返回来源、物理页和块；
- 学术史条目与期刊模板可在 GUI 中创建和查看；
- 自动化测试覆盖上述门禁，Demo 可在 8765 打开。

## 不在 D2

无人监督的整篇长文生成、模仿具体在世作者、自动决定史学贡献、绕过数据库许可、自动提交期刊、
完整 DOCX 排版、生产级爬虫集群和自由扩散的多 Agent 写作。
