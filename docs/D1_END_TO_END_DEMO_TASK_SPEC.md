# D1 Task Spec｜Conversation-first End-to-End Demo

状态：已批准，实施中
日期：2026-08-10

## 目标

把 M1-M5 的页面清洗、Agent 工作区与研究图书馆合并为一个可实际操作的完整 Demo。主界面是持续对话；项目、文献、原页、检索、论点、证据、冻结包和写作产物都是对话可引用的研究对象，而不是彼此分离的功能页。

## 主界面

- 左侧：项目切换、新建项目、研究线程；
- 中间：教授与唯一主 Agent 的持续对话；
- 右侧：项目文献、图书馆、联网研究、原页与异常、论点与证据、冻结与写作、研究浏览器、记忆候选；
- 图书馆仍保留完整管理视图，但不再作为启动首页。

## 必须打通的纵向闭环

1. 新建或切换项目；
2. 从研究图书馆选择具体文件版本，复制为项目内不可变来源并执行 PDF 页面处理；
3. 通过 Crossref/OpenAlex 进行有界公开检索，完整保存检索式、时间、结果和失败状态；可只读探测 Zotero 本地 API；
4. 从已验收页面块建立 Evidence Item，并连接到 Claim；不合格页面不得提交为证据；
5. 人工批准 Evidence Freeze，冻结原文、物理页、来源版本和主张关系；
6. 只依据已批准冻结包生成可追溯的 Markdown 试写，记录评审并导出；
7. 浏览器工作区保存域名授权和操作回执，下载材料仍进入人工验收；
8. 研究判断只能先成为带来源的记忆候选，再由用户批准。

## 研究浏览器的 Demo 边界

- 提供专用研究浏览器面板、起始网址、允许域名、外开页面和 session receipt；
- 公开检索 connector 可真实调用；
- 登录、验证码、付费墙、下载、提交和批量动作交回用户；
- 不读取或保存 Cookie、密码、令牌和完整网络日志；
- 跨站 Computer Use、浏览器标签附着和自动下载属于桌面阶段，不在本轮伪装实现。

## 版本与来源规则

- SHA-256 只标识精确字节版本；文字变化不使 Work、Edition 或 File 身份失效；
- Evidence Freeze 保存所用 Source Version 的哈希与页块锚点，而不是要求当前文件永远保持同一哈希；
- 来源更新后，旧冻结包继续可审计，新写作必须明确选择继续使用旧版本或重新核验；
- 检索结果、摘要、网页线索和图书馆条目默认都不是可引用证据。

## 完成标准

- 重启后项目、线程、检索记录、证据、冻结包和写作版本均可恢复；
- 图书馆文件加入项目时不修改原件，项目来源可返回精确图书馆版本；
- 阻塞页/块无法创建已核证证据；
- 未批准冻结包无法驱动正式试写；
- 每段试写可回到 Claim、Evidence、物理页和精确来源版本；
- 浏览器 session 不持久化任何凭证；
- GUI 能完成上述流程，自动化测试覆盖关键门禁和旧数据库迁移。

## 明确不做

桌面安装包、任意 Skill 脚本执行、后台全盘扫描、自动登录数据库、自动绕过验证码或付费墙、无人批准的证据冻结、整篇论文自动生成、自动写入外部长时记忆、生产级向量数据库。
