# D3 Demo Task Spec｜Research Object Workspaces

状态：实施中
日期：2026-08-10

## 目标

把 D1/D2 的可运行能力重组为一个可试用的史学研究客户端 Demo。顶层只保留研究对话、研究图书馆、
文章工作台和项目设置；导入与原页修复进入图书馆文献详情；文章工作台以结构化稿件版本为内部对象，
并允许研究者带着当前章节和选区与同一个主 Agent 讨论。

## 本轮可见能力

1. 四个永久工作空间，旧 D1/D2 API 与数据继续可读；
2. 图书馆收件箱同时支持明确目录的只读盘点和单份 PDF 导入；
3. 项目文献可从图书馆详情打开原页复核，不再把“文献修复”放在顶层；
4. 稿件采用带稳定节点 ID 的结构化文档树，人工保存产生不可变修订；
5. Markdown 与受控 DOCX 导入/导出生成 fidelity report；
6. 文章侧栏绑定 thread、manuscript、revision、section 与选区快照，聊天不自动写入正文；
7. 浏览器占据中央工作区，记录 URL、允许域与会话回执；嵌入受站点策略限制时提供系统浏览器入口；
8. 设置页集中显示模型角色、视觉/翻译辅助模型、Skills、连接器、隐私与版本信息。

## 明确不做

- 不迁移或删除真实项目的旧 Page/Block/Repair 表；
- 不声称复杂 DOCX 可无损往返，不支持修订模式、批注、域代码和嵌入对象保真；
- 不绕过数据库许可证、付费墙、验证码或访问控制；
- 不允许对话或模型建议静默进入已批准正文；
- 不进行桌面打包、凭证采集或无人值守浏览器操作。

## 验收

- 旧 schema 项目升级后原来源、线程、证据与稿件仍可读取；
- 结构化稿件保存后产生新修订，旧修订内容不变；
- 选区对话可回显绑定的稿件、修订、章节、节点和文本哈希；
- Markdown 与简单 DOCX 完成导入/导出并返回明确的保真报告；
- 顶栏不再出现全局 PDF 导入、来源选择或独立文献修复入口；
- 真实 PDF 可在图书馆流程中进入项目并打开原页复核；
- 全部既有测试与 D3 新增测试通过。
