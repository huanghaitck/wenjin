# 问津 0.1.3 更新说明

0.1.3是问津首个以Codex app-server为单一Agent执行基底的正式版本。本版重点不是继续增加菜单，而是把研究者最常使用的“找资料—采用—清洗—回到原页”链路和三类知识图谱修到可以连续使用。

## 自然语言使用图书馆

- 主Agent可以从含糊的研究描述中提取题名、作者、地点、时代或主题关键词；
- 检索覆盖题名、作者、期刊/出版社、标签和入库预览文本；
- 找到候选后，Agent会读取作品与精确文件版本，而不是仅凭题名猜测；
- 用户要求采用时，`library.add_to_project`会遵守当前权限模式：请求批准模式先暂停，批准后在同一运行中继续；
- PDF采用后生成可回查的物理页与文本块，DOCX采用后生成定位文本；原文件不移动、不覆盖。

真实验收使用“史姓学者写外国人眼里的西安城”一类模糊描述，主Agent成功找到史红帅论文、谭卫道研究和谭卫道日记；第二轮选中正确PDF，等待人工批准后在临时项目建立来源并完成页级清洗。

## 三种知识图谱

知识图谱页只保留画布和必要控制，不再向下堆叠作品卡、Markdown卡与关系清单。

1. **作品关系**：默认只显示已经归入原始史料、学术论文、学术专著、本人文章与稿件或工具书的作品。读书笔记仅在用户明确要求时临时纳入，待分类文件在完成书目判断前不进入图谱。不同材料类别分色；同作者、同出版社、同期刊、引用、材料使用、评述、翻译和提及关系分别着色，有向知识关系带箭头。期刊论文与专著即使登记了同一机构，也不会被误折叠为“同出版社”关系。
2. **书目实体**：展开作品、作者、期刊/出版社、年份和材料类型。中外文作者别名只有经过人工核定才合并。
3. **项目内容实体**：显示来源、页面、Markdown文本、事件、共享实体、主张和证据，继续保留来源页锚点。

作品关系、书目实体和项目内容实体各有独立图例，不再共用一套节点或关系说明。作品图默认勾选引用、材料使用、评述、翻译和提及等核心关系；取消勾选时，关系线和相应图例项同时隐藏。引用边为红色有向箭头。单击节点只聚焦邻居；连续双击才在右侧打开与图书馆一致的作品卡或来源卡。画布支持滚轮缩放、空白处或中键平移、题名悬浮/常显、节点与关系筛选。

## 界面与项目回跳

- 图谱页默认收起详情侧栏，双击节点后才展开；
- 侧栏控制改为图标，并同步中英文标题和辅助说明；
- 图书馆页面不再显示独立的全项目文献下拉框；
- 已采用作品直接显示“打开该文献的项目原页”；
- 搜索结果切换后，右侧详情自动跟随当前结果，不再停留在旧作品；
- 图书馆使用内部滚动区域，页面最右侧不再常驻额外滚动条。

## 运行与兼容

- Windows安装包自带冻结Python核心、Codex app-server与桌面运行时；普通用户不需要另装Python、Node.js、PowerShell 7、Rust或Codex；
- DeepSeek Responses API是主要实测模型通道；Ollama兼容可用，但小模型是否稳定选择工具仍取决于模型本身；
- 自包含领域Agent继续通过MCP保持可移植性，私人灾害史Agent和研究数据不进入公开包；
- Codex后端与旧运行器共用自然语言领域路由，普通表述命中领域任务后会直接委派已安装领域Agent；
- 当前只发布Windows 10/11 x64，安装程序尚未代码签名，无自动更新，macOS尚未真机构建。
