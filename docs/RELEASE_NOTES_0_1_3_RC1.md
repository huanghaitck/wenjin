# 问津 0.1.3 RC1 更新说明

本候选版针对新电脑安装、主 Agent 自检和全库实体图谱进行修复。

## 运行环境

- 问津核心与自包含领域 Agent 不要求系统安装 Python 或 PowerShell；
- 主 Agent 可先调用运行环境自检，识别 uv Python、PowerShell 7 和应用自身运行时；
- 仅当用户明确运行外部脚本且本机确实缺少环境时，才在权限确认后安装可选组件；
- 深度推理和工具结果较多的轮次会自动获得更长模型等待时间，轻量轮次仍保持短超时；安装或长脚本由工具单独声明上限，不取消安全超时。

## 图谱与图书馆

- 书目实体图谱由 fCoSE 统一处理断开的分量，避免多个网络叠在中心；
- 全库概览保留缩放、平移、悬浮题名、邻接高亮和双击详情；搜索后只显示相关子图；
- 自动盘点排除 HistRA-Bench、MCQ、pytest、`.codex-work` 等评测与工程材料；
- 提供可恢复清理脚本，清理书目登记前先备份数据库，原始文件保持不变。

## Harness 边界

RC1参考 OpenAI Codex app-server 的公开线程生命周期、流式事件、审批、中断/恢复和隔离测试模式。问津继续保存自己的研究项目、来源、证据与人工判断；可选 Codex 桥接不会替代这些状态。

## 候选版验证

RC1必须通过完整 Python 测试、桌面侧车烟雾测试、安装包启动、内置 Computer Use 更新、领域 Agent 自包含运行和知识图谱整窗检查后，才可升级为正式版。
