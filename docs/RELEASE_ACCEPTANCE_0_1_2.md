# 问津 0.1.2 发布验收表

0.1.2继承0.1.1全部公开能力，本表补充本次图书馆和书目关系图谱变化。发布必须通过自动测试、真实浏览器界面和干净安装包三层验收。

| 验收对象 | 0.1.2完成标准 | 验证方式 |
|---|---|---|
| 版本 | Python、MCP、Tauri、Cargo、Node与文档版本均为0.1.2 | 版本扫描与安装包启动页 |
| 入库题名 | 清洗文件名优先；编号或哈希名才回退内嵌题名；制作软件元数据不进入作者、出版社或年份 | 单元测试与真实书库抽查 |
| 作品去重 | 同一作品只显示一个书目节点，同时保留多个文件位置和精确版本 | 单元测试与真实书库抽查 |
| 读书笔记 | 独立书架；不进入书目关系图谱 | 单元测试与界面检索 |
| 图谱节点 | 仅显示作品，不显示作者、年份、书架和类型等中间节点 | API与浏览器验收 |
| 图谱关系 | 同作者、同出版社、同期刊、同年代（十年）及有向知识关系；不显示同类型或同书架关系 | API关系集合断言 |
| Markdown关系 | 脚注、尾注和参考文献精确题名自动建立引用；正文精确题名建立提及；明确措辞建立翻译、评述或材料使用关系 | 单元测试与来源回跳 |
| 图谱布局 | fCoSE处理关系簇；孤立节点稳定散布外围；全部节点坐标有限且可见 | 真实225节点书库验收 |
| 图谱交互 | 滚轮缩放、空白处或中键平移、悬停题名、单击聚焦、双击书目卡、搜索子图 | 浏览器真实操作 |
| 公开边界 | 不包含领域Agent私有包、用户数据库、API密钥、Cookie、历史记忆库或真实研究候选数据 | 发布目录与压缩包扫描 |

## 继续适用的限制

- 安装程序未签名，无自动更新；
- macOS尚未完成真实设备构建；
- 自动题录和作品合并仍需研究者抽查；
- 复杂DOCX往返仍需在Word中复核；
- 受限数据库不提供验证码绕过或无人值守批量下载；
- 实体消歧图谱不属于本次更新范围。
