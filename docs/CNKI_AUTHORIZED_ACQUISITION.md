# 知网授权会话采集边界

## 目标

在研究者本人已经登录并具有相应下载权限的可见浏览器会话中，协助完成检索、候选确认与文件下载。程序不实现面向知网的批量爬虫。

## 允许的动作

- 研究者在可见浏览器中自行登录，程序不保存账号、密码、Cookie 或机构凭据。
- Agent 按研究任务生成检索式，模拟正常的搜索、翻页、打开条目和点击下载。
- 下载前展示题名、作者、刊名、年份、卷期和文件格式，由研究者决定是否取得。
- 保存检索式、条目网址、下载时间、文件格式和精确文件版本回执。

## 禁止的动作

- 绕过验证码、付费墙、下载频率限制或机构许可。
- 批量抓取全文、复用或导出登录凭据。
- 把搜索结果页、摘要或目录自动升级为可引用正文证据。

## PDF 与 CAJ

1. 同一版本可选时优先 PDF：原页、印刷页码和版面关系更容易稳定保留。
2. 仅有 CAJ 时保留原 CAJ，不覆盖、不删除；转换所得 PDF 和逐页 Markdown 都是派生版本。
3. 转换必须生成回执，记录工具版本、输入文件指纹、输出文件指纹和页数差异。
4. 任何正文引证仍须回到人工核验的原页；转换文本只用于检索和定位。
