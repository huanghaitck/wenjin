# 历史论文评审与返修

完整读取 [核心政策](../../references/core-policy.md) 和 [项目阶段](../../references/project-stages.md)。

## 评审

1. 为每个 Reviewer 规定互不重叠的角色、必读输入、输出字段和禁止事项。
2. 多 Agent 必须得到明确授权；独立评审不得读取其他 Reviewer 意见。
3. 每条意见标明证据、严重度、影响主张和建议门禁，不用总分代替判断。
4. 合并共同争点和真实分歧，保留少数意见。

## 答辩与返修

1. 唯一作者逐条接受、部分接受或拒绝，并说明理由。
2. 事实、页码和引用问题退回证据层；结构与措辞问题才在稿件中处理。
3. 只产生一个返修稿，保存改动日志和未解决项。
4. 返修后交给 `historical-final-audit`；语言问题在事实终审后再交 `historical-prose-revision-zh`。
