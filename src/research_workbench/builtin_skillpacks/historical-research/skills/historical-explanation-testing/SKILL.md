# 历史解释检验

完整读取 [核心政策](../../references/core-policy.md) 和 [方法摘要](../../references/methodology.md)。

1. 把论点拆成可单独判断的描述、解释、因果、比较和外推主张。
2. 为每项强主张建立至少两种竞争解释。
3. 检查时间顺序、机制桥梁、来源独立性、循环论证和从个案到总体的外推阶梯。
4. 主动寻找最危险的反证和能够区分解释的最低证据。
5. 写明证据出现时应维持、缩小、合并、暂缓还是淘汰主张。
6. 阴性证据只在检索范围和材料预期明确时使用。

多 Agent 可在用户授权后承担独立反方或不同竞争解释，但不得读取彼此结论后伪装独立。主 Work 汇总为竞争解释矩阵和失败测试。
