# 史学文献检索

先完整读取 [核心政策](../../references/core-policy.md)、[来源提供者政策](../../references/source-provider-policy.md) 和 [史学证据契约](../../references/evidence-contract.md)。

## 搜索设计

1. 写明触发原因、问题、时段、地域、人物、制度和稳定专名。
2. 分开检索一手史料、直接研究、邻近研究、方法研究和结构范例。
3. 优先查询用户已授权的本地文库和 Zotero，再按开放 API、公开网页、学术索引、受限数据库的次序查询网络资源。
4. 使用多语种、异名和旧译名，但记录每条查询式。
5. 预先设定最多轮次、来源范围和停止条件。
6. 为每条重要命中建立 Retrieval Record，记录提供者、排名、稳定标识、开放副本、访问状态和预期用途。

## 取得与失败

- 网页提供公开文件时，在用户授权的目录实际保存并验收；不要因保护阅读器直接判定不能下载。
- 记录 HTTP 状态、认证、付费、验证码、馆方申请或无公开文件地址等真实限制。
- Google Scholar 等学术索引只用于发现；优先追索 DOI、期刊官网、作者自存稿和机构知识库中的开放副本。
- 中国知网等受限数据库允许登记题录和用户可访问的全文，但不得批量抓取、绕过权限或保存用户密码。
- 中国哲学书电子化计划、维基文库等开放文本仍须登记底本、版本、页面或稳定文本标识；开放不等于已取得证据资格。
- 同源镜像不重复计数；失败下载不升级为材料。
- 每轮保留阴性结果及其检索范围。

使用 `../../assets/templates/search_log.csv` 记录结果，并运行 `../../scripts/validate_search_log.py`。把实际取得文件交给 `historical-material-intake`；把未取得但相关的材料交给用户选择队列；把“未发现”表述为限定范围内的结果。
