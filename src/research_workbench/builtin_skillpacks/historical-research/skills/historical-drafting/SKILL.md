# 历史论文写作

完整读取 [核心政策](../../references/core-policy.md)、[项目阶段](../../references/project-stages.md) 和 [方法摘要](../../references/methodology.md)。

1. 核对冻结包、论证图、目标体例、篇幅和允许写入的文件。
2. 只建立一个正式写作主体；其他 Agent 不得同时改同一正文。
3. 以具体行动者、材料、动作和时间推进论证，脚注从冻结库按语境插入。
4. 不用背景填充篇幅，不把同一判断换词重复，不把来源边界写成连续自我辩护。
5. 新问题按 R0—R3 分类：R0 内部解决；R1/R2 暂停相关主张并退回；R3 等待人工批准。
6. 不因写作需要静默提高因果强度或把同源来源写成独立证据。

输出唯一稿件、实际使用的 claim/citation 清单、未使用证据和缺口票。不得在本技能内宣布终稿或投稿通过。
