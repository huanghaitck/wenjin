# 来源提供者与联网检索政策

联网检索是本插件的核心能力。插件按提供者的公开能力、访问条件和证据用途选择不同路径，不假设所有网站都具有公开 API，也不把搜索结果当成材料全文。

## 优先顺序

1. 用户明确授权的本地文库、项目目录和 Zotero。
2. 官方开放 API、公共领域全文库和机构开放仓储。
3. 可公开阅读或下载的数字馆藏与期刊官网。
4. Google Scholar、OpenAlex、Crossref 等学术发现和标识服务。
5. 中国知网等需要登录、订阅、付费或机构权限的数据库。

## 提供者类型

### `OPEN_API`

例如中国哲学书电子化计划、Wikimedia/维基文库和开放书目服务。遵守官方限流、认证、许可和返回格式；保存稳定标识和查询时间。电子文本仍需核底本与版本。

### `PUBLIC_WEB`

例如提供公开搜索和在线阅读、但没有已核实开放 API 的古籍平台或数字馆藏。使用用户可见的网页和正式下载入口，不探测隐藏接口，不批量规避访问限制。

### `DISCOVERY_INDEX`

例如 Google Scholar。用于发现题名、作者、DOI、被引关系和开放副本。不得批量抓取明确限制自动访问的服务；排名和引用次数不代表史学证据强度。

### `RESTRICTED_DATABASE`

例如需要登录或机构订阅的全文数据库。允许记录公开题录和用户通过合法会话访问的文件；不得绕过付费、验证码或机构权限，不在对话、项目文件、日志或长期记忆中保存密码、Cookie和令牌。

## 开放全文

发现开放文件后应实际保存到用户授权目录，并检查格式、文件头、字节数、页数、哈希和代表页。HTML错误页、未完成下载和阅读器占位页不得升级为已取得全文。

## 受限材料队列

不能取得全文时，至少登记题名、作者、年份、期刊或馆藏、稳定链接、与当前问题的关系、预计核验的主张、访问限制、已检查的开放替代入口、优先级和用户动作。

推荐访问状态：

- `OPEN_FULLTEXT`
- `OPEN_WEB_TEXT`
- `METADATA_ONLY`
- `AUTH_REQUIRED`
- `INSTITUTIONAL_ACCESS_REQUIRED`
- `PAYWALLED`
- `CAPTCHA_OR_READER_BLOCKED`
- `OPEN_COPY_NOT_FOUND`
- `USER_SELECTION_REQUIRED`

题录和摘要只能用于选择材料，不能承担论文事实或作者论点。

## 可选 MCP

核心插件可使用宿主已有的网页、浏览器和下载工具，不依赖自建服务器。未来 MCP 只作为开放来源适配、持久证据账本或正式 OAuth 集成的可选组件。任何连接器都必须返回提供者、查询、稳定标识、访问状态和原始入口，不能只返回无来源摘要。
