# 史学证据契约

本契约规定十六个技能共同维护的证据对象。目标不是让系统“看过很多材料”，而是让每条重要判断能够回到具体来源、版本、位置、上下文和核验状态。

## 四类对象

### Retrieval Record

记录材料怎样被发现：查询式、提供者、日期、结果排名、稳定标识、开放副本、访问状态、下载尝试、阴性结果和停止条件。检索命中只说明“值得继续查”，不授予阅读或引用资格。

### Source Object

记录材料身份：作者、题名、形成或出版时间、版本、语言、载体、文件哈希、页数、权利范围，以及原件、译本、重印、OCR、摘录和镜像关系。每个载体使用稳定 `source_id`；共享同一叙述者或母本的材料归入同一 `independence_group`。

### Evidence Item

记录承担分析的具体文本、档案页、地图、照片、表格或物质对象。至少包含：

- `evidence_id` 与 `source_id`；
- 原书页、数字页、档号或稳定文本锚点；
- 必要上下文；
- 材料明确记载；
- 材料作者解释；
- 当前研究者推论；
- 能支持、不能支持和可能反驳的主张；
- 页级或对象级核验状态。

OCR、摘要、搜索片段和自动生成的相似度只用于定位。关键事实必须回到原页、档案图像或稳定数字文本。

### Claim Link

记录证据与论文主张的关系：`supports`、`contradicts`、`contextualizes` 或 `does_not_support`。同时登记主张强度、竞争解释、危险反证、来源独立性、完整和简化脚注，以及允许写入正文的最低表述。

## 证据状态

`DISCOVERED → ACQUIRED_UNVERIFIED → FILE_VERIFIED → METADATA_READ → TARGETED_READ → FULL_READ → PAGE_VERIFIED → CITABLE`

状态不能跳级。开放获取、文件存在或全文阅读均不自动等于所有片段已经核页。

## 图像与地图

图像、地图、表格和折页不是正文附件的附属物。它们应拥有独立 `evidence_id`，记录题注、来源、页码、图像范围、是否完整、与正文关系及可支持的视觉判断。

## 阴性结果

“未发现”必须同时记录查询式、数据库、时段、语言、轮次和停止条件。只有材料在该情境下本应记录而未记录时，沉默才可能进入解释；普通检索无结果不得写成历史对象不存在。

## 冻结条件

进入正式写作包的 Claim Link 必须满足：来源身份清楚、定位已核验、证据边界完整、同源关系已处理、竞争解释已登记、脚注可生成。未满足者只能是 `CONTEXT_ONLY`、`UNRESOLVED` 或 `PROHIBITED_CLAIM`。
