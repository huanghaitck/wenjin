# 与史学长期记忆库协作

## 1. 路径与职责

史学长期记忆库路径由研究者在问津“AI 与 Agent—记忆”中配置。公开安装包不预设个人绝对路径，也不附带任何私人记忆内容。

`historian-memory` 负责来源登记、论文分类、阅读状态、个人画像和批准记录；本技能只负责在证据保护条件下执行语言级修订。

## 2. 偏好可信度

- `OBSERVED_ONCE`：只作为候选，不自动应用。
- `RECURRING`：说明特征复现，仍需用户判断。
- `AUTHOR_APPROVED`：可以作为当前默认偏好。
- `STABLE_PROFILE`：可跨项目调用，但仍服从投稿规范和本项目证据。
- `REJECTED`：禁止再次采用。

当个人偏好与事实、引文、限定、期刊规范冲突时，后者优先。

## 3. 使用顺序

1. 检索与稿件类型相同或相近的个人画像。
2. 读取用户明确批准与拒绝的修改对照。
3. 区分跨项目稳定偏好和单一项目决定。
4. 对高风险段落先给候选，不直接写入全文。
5. 用户批准后，把选择结果交回 `historian-memory` 更新。

## 4. 禁止

- 不把参考学者的风格卡当作措辞生成器；
- 不把一篇个人论文中的语病、重复和格式问题记为个人风格；
- 不因“个人声音”改变事实强度或史料边界；
- 不把整个记忆库加载进上下文；
- 不在未经授权时把私人论文或画像发布到外部服务。
