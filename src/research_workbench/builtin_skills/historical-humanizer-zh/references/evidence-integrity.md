# 证据完整性规则

## 目录

1. 保护层级

## 1. 保护层级

把历史学稿件分为三层：

- `P0 精确冻结`：任何字符变化都需人工批准。
- `P1 语义冻结`：可以改句法，但命题、强度、范围和归因必须完全不变。
- `P2 语言可修`：只允许改善表达、节奏和段落衔接。

先识别 P0 和 P1，再处理 P2。不得先改全文、事后寻找受损内容。

## 2. 精确保护项目

把以下内容列为 P0：

- 直接引文及其中文译文；
- 块引文、行内引号中的史料文字；
- 脚注标记、脚注正文和再次引用格式；
- 原印页、本地 PDF 页、档号、卷期、版本、出版地、出版社和年份；
- 人名、地名、机构名、书名、专门术语和多语种转写；
- 阿拉伯数字、罗马数字、日期、数量、比例、单位和数字范围；
- 西里尔字母及其他非中文书目信息；
- 图表、地图、题注、来源说明、图片路径；
- URL、DOI、档案馆链接；
- 项目指定不得改变的标题、关键词和术语。

若某段含 P0 内容，优先改写其周围分析句，不改 P0 本身。

## 3. 语义保护项目

把以下内容列为 P1，并逐项人工复核：

- 谁在何时、何地做了什么；
- 行动和材料的时间顺序；
- 作者、旅行者、档案或现代学者之间的归因；
- 事实、推断、比较和方法语言的证据等级；
- 因果方向以及是否仅为相关、条件或可能性；
- 个案、区域、时代和群体的外推边界；
- “可能”“尚不足以”“只能说明”“未见”“不能据此”等限定；
- “有些”“在此个案中”“最有把握”“再进一步”等范围或证据等级标记；
- 阴性结果、缺失材料和无法核实事项；
- 竞争性解释及其仍未排除的部分；
- 匿名或弱势行动者没有留下的声音。

脚本无法保证 P1。必须由主编或证据审计者复核每一处 diff。尤其注意：同一个限定词若在一处被删除、在另一处被添加，全文数量和字面序列仍可能通过；这不证明它仍限定原来的命题。

## 4. 允许与禁止的语言修改

允许：

- 删除不承载史实的内部流程语言；
- 把具体史实移到抽象概念之前；
- 把无明确主体的抽象句改为材料或行动者作主语；
- 合并重复总结；
- 调整句长、断句和段落衔接；
- 将证据边界移到相应推论旁边；
- 在不改变含义时恢复稳定术语。

禁止：

- 用更具体的细节替换原稿没有的内容；
- 删除看似啰嗦但承担证据限定的句子；
- 把“可能”改成“说明”或把“不能证明”改成“表明”；
- 为了去掉编号层级而合并不同证据强度的判断；
- 把旅行者判断写成客观事实；
- 把现代研究写成一手证据；
- 把多个年代或地区材料拼成同一统计序列；
- 为改变节奏而调换历史动作顺序；
- 为“人味”加入作者未表达的感受、犹豫或发现；
- 为避免重复而替换已经定义的核心术语。

## 5. 保护词表

对专名和项目术语使用 UTF-8 文本文件，每行一个必须原样保留的字符串：

```text
# 以井号开头的行是注释
皮亚塞茨基
乌尔穆格图伊
Bain-Gol
环境知识
可能
尚不足以
```

词表只检查字面一致性。不要把全部中文常用词列入，以免产生无意义警报。

## 6. 失败处理

- 精确保护项目变化：`BLOCKED_PROTECTED_CHANGE`，恢复基线。
- 语义边界不确定：`MANUAL_REVIEW`，保留原句和候选句并列。
- 需要新事实或引用：`SUBSTANTIVE_RETURN`，退回研究阶段。
- 只涉及可验证语言变化：`PASS_STYLE_ONLY`。
- 独立审计失败：由改写者作最小修复并重建派生文件，再由独立审计者复审；审计者不得自行改稿。

不要用“整体意思差不多”覆盖任何失败。
