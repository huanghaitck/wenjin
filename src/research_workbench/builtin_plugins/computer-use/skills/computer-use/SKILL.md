# Computer Use

Use the accessibility snapshot before choosing a control. Refresh the snapshot after window changes because refs can become stale. Never enter password controls or claim that a click, key sequence, program launch, or command ran without a completed tool receipt. The active Wenjin access mode determines whether state-changing actions pause for approval, are risk-approved, or run with full-computer access.
